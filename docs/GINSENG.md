# Ginseng — слон

Герой реализован в движке, интерфейсе, драфте и сохранениях. Обычные перемещения и взятия — как у слона. В драфте заменяет одного из своих слонов: c1/f1 у белых, c8/f8 у чёрных. В режиме «Тест скиллов» стоит на f1/f8 и отмечен буквой **G**.

## Скилл — Переместить фигуру

Выбирает одну союзную или вражескую фигуру, кроме короля, в радиусе **3**. Радиус охватывает всю область до трёх клеток по каждой оси; препятствия выбору не мешают. Самого Ginseng тоже можно выбрать.

Перемещает цель на любую свободную из восьми соседних клеток вокруг её исходного места. Клетка назначения может оказаться дальше трёх клеток от Ginseng: ограничение радиуса проверяется для исходной цели. Взятия занятой клетки этой способностью нет. **КД — 3 собственных хода**, уменьшается в начале собственного хода.

Пример: Ginseng на c2 может выбрать фигуру на f5 и поставить её на g6, если клетка свободна и результат допустим по безопасности короля. Сдвиг не считается обязательным обычным перемещением. Вход во вражеское болото запускает ловушку; побочные взятия получает владелец ловушки. Принудительное перемещение сохраняет ID и эффекты фигуры и обновляет шахматные права через общий обработчик действий.

В интерфейсе: выбрать Ginseng → **«Переместить фигуру»** → выбрать фигуру → нажать подсвеченную свободную клетку. Кнопка **«Выбрать другую цель»** возвращает к выбору фигуры.

## Ульта — Копировать последнее

**Стоимость — 2 собственных взятия**, включая пешек. Заряд ограничен двумя; успешная кража расходует два. Отдельного КД нет.

Игрок выбирает любого союзного или вражеского героя на доске, без ограничения расстояния. Ginseng получает копию **последней успешно применённой активной способности именно этой фигуры** — обычного скилла или ульты. Выбирать между ними вручную нельзя. Пассивки, обычные ходы и отклонённые попытки применения не меняют последнюю способность. Если герой ещё не применял активную способность, копировать нечего: действие отклоняется без расхода заряда и лимита хода.

У исходного героя способность остаётся. Одновременно хранится одна копия; новая успешная кража заменяет прежнюю. Перемещение или последующая гибель исходного героя не уничтожают уже полученную копию: источник связан с постоянным ID, а не клеткой.

Копия доступна **со следующего собственного хода Ginseng**, хранится без ограничения времени и исчезает после одного успешного применения. Дополнительные заряд ульты и КД для применения копии не нужны, собственные КД и заряд Ginseng не расходуются. Ограничения целей и эффекта исходной способности сохраняются. При отказе копия остаётся.

Получение копии и её применение занимают обычный общий лимит **одной способности за ход стороны**. Поэтому украсть и применить в том же ходу нельзя. И получение, и применение копии не заменяют обязательный обычный ход фигурой. Способность до обычного хода должна оставить допустимое продолжение; после любого действия свой король должен быть в безопасности.

В интерфейсе: **«Копировать последнее»** → выбрать героя. Полученная способность появляется отдельной кнопкой **«Использовать: …»**. Для сдвига остаётся выбор цели и новой клетки; способности без цели применяются кнопкой сразу.

## От кого действуют скопированные способности

| Копия | Эффект от Ginseng |
| --- | --- |
| Хук Пуджа | Тянет к самому Ginseng по тем же восьми направлениям в радиусе 3 |
| Проглатывание Пуджа | Союзник хранится внутри Ginseng. При взятии Ginseng выходит и берёт атакующего по обычным правилам реакции |
| Лазер Lumeshard | Накладывает ослепление от Ginseng, с исходными радиусом и длительностью |
| Телепорт Lumeshard | Переносит на пустую клетку цвета **стартовой клетки Ginseng**. Цвет запоминается при создании и не меняется после сдвига на другой цвет |
| Метка Crow | Награда действует с теми же сроками и выплачивается взявшей стороне; пассивку Crow Ginseng не получает |
| Кража золота Crow | Переводит до 2 золота из кошелька соперника владельцу Ginseng |
| Грязь Bolotnik | Ловушка принадлежит Ginseng; при срабатывании перемещается тот же Ginseng, оставаясь слоном |
| Засада Bolotnik | Прячет самого Ginseng; при срабатывании он выходит на клетке жертвы |
| Призыв Избы | Создаёт настоящую Бабу-ягу стороны Ginseng; она позже превращается в Избу. Пассивка Избы не копируется |
| Сдвиг Ginseng | Те же цель и соседняя свободная клетка; без собственного КД Ginseng |
| Копирование Ginseng | Копирует последнюю способность выбранного героя и создаёт новую одноразовую копию, доступную со следующего собственного хода |

Сроки метки, ослепления, грязи и жизни призванной Бабы-яги сохраняются после расходования копии. Проглоченный союзник и скрытие в болоте тоже продолжают действовать. Взятия, совершённые самим Ginseng через копию или её последствия, дают ему обычную награду и заряд его собственной ульты.

Если выбран другой Ginseng, который последним действием получил копию, копируется именно его **ультимейт копирования**. Если он последним применил украденный хук, копируется хук. Содержимое его текущего слота не подменяет историю последней активации.

## Модель и API

Пакет `game.heroes.ginseng` содержит `GinsengRules`, `GinsengAbilities`, `BorrowedEffects`, `BorrowedAbility`, `SpellState`, `SpellValidator`. Правила прототипа: `new GinsengRules(3, 2)`; тестовый режим снимает КД и стоимость собственной ульты.

`SpellState.lastUsed` связывает ID фигуры с её последней успешной активной способностью. `SpellState.borrowed` хранит по одной копии на ID Ginseng: способность, источник и ход получения. История `GameEvent` содержит признаки `borrowed` и `copiedAbility`; память восстанавливается из принятых событий. Отказы и предварительные проверки не меняют её.

Для сдвига нужна отдельная клетка назначения, поэтому добавлена команда `AbilityRequest`. Старое трёхаргументное применение способностей сохранено:

```java
// target — перемещаемая фигура; destination — свободный сосед цели.
game.useAbility(player, new AbilityRequest(actor, Ability.DISPLACE, target, destination, false));

// Копируется последнее применение выбранной фигуры автоматически.
game.useAbility(player, actor, source, Ability.COPY_SPELL);

// Применение хранящейся копии. Способность должна совпасть с содержимым слота.
game.useAbility(player, new AbilityRequest(actor, Ability.HOOK, target, null, true));
```

`Game.getAbilityTargets(actor, ability, borrowed)` и `getDisplacementDestinations(actor, target, borrowed)` используют тот же путь проверки, что команда. `getAbilityAvailability` имеет перегрузку с `borrowed`. Результат каждой команды необходимо проверять через `MoveResult.isSuccess()`.

Копии используют существующие реализации способностей через отдельное представление исполнителя. Перед публикацией сохраняются реальные ID, тип слона, герой Ginseng, инвентарь, исходный цвет и собственные ресурсы. Общая обработка проводит реакции, экономику, болото, призыв, безопасность короля и возможность завершить ход.

## Сохранение, драфт и проверки

XML **7** хранит `ginsengRules` и метаданные событий. Отдельной XML-секции копий нет: последняя способность, оставшаяся копия, момент её готовности и факт расходования восстанавливаются из журнала. Подмена способности, неправильный источник, несоответствие истории и применение ещё не готовой копии отклоняются. Эффекты старых героев от Ginseng также сохраняются.

Каталог драфта **3** добавляет Ginseng шестым героем. После двух банов остаются четыре героя. Каталоги 1/2 и сохранения XML 1–6 продолжают восстанавливаться по прежним правилам. Новые драфты используют XML 7, даже если Ginseng забанен.

`GinsengTest` проверяет радиус, сдвиг, шах, бюджет, заряд, последнюю успешную способность, готовность и расходование копии, замену и все существующие копируемые эффекты. `GinsengSaveTest` проверяет XML 7, отказы на повреждённые данные и совместимость старого формата. `GinsengUiTest` проверяет реальные клики драфта, выбор двух клеток и применение копии; изображения создаются в `composeApp/build/ui-previews`.
