# Проверяемая исходная точка перед миграцией героев

Зафиксирована 20 октября 2026 года. На момент фиксации новый слой
`Hero` / `AbstractHero` / `PudgeHero` существовал параллельно игровому пути
через `HeroAbilities` / `*Abilities`. Последующее подключение описано
в [HERO_MIGRATION.md](HERO_MIGRATION.md); этот документ сохраняет исходный результат.

## Причина восстановления

В merge-коммите `3788fee` форматирование из ветки `3cd5f8a` перекрыло часть
функциональных изменений из родительского коммита `f624241` (`New Hero: Zeus`).
Часть способностей и тестов новых героев осталась в проекте, но общие модели,
диспетчеризация, драфт и сохранения потеряли соответствующие расширения.

До восстановления прямая компиляция Java-ядра показывала 164 ошибки.
Полный Gradle-прогон также останавливался на компиляции Kotlin-интерфейса
из-за отсутствующих полей снимка, методов состояния и значений `Ability`.

## Эталон и границы изменений

- Java-исходники и существующие Java-тесты из `f624241` проверены в отдельной
  временной директории: компиляция успешна, 549 тестов проходят.
- В 26 Java-файлах восстановлены потерянные при merge функциональные изменения.
  Существующее форматирование сохранено в неизменённых участках.
- После восстановления последовательности исполняемых Java-токенов во всех
  130 ранее существовавших Java-файлах совпадают с `f624241`.
  Пробелы и комментарии при сравнении не учитывались.
- Новые `Hero`, `AbstractHero`, `HeroActionContext`, `PudgeHero` и их 19 тестов сохранены.
- Шесть UI-тестов драфта использовали небольшие значения прокрутки колеса, зависящие
  от платформы. На macOS нужная карточка не попадала в область нажатия.
  Общий тестовый помощник `DraftUiActions.kt` прокручивает каталог до последнего героя
  и продвигает часы кадров для завершения анимации. Проверки выбранных героев сохранены;
  код экрана драфта и игровые правила не изменены относительно эталона.

## Результат проверки

Команда из корня проекта:

```sh
bash gradlew :composeApp:jvmTest
```

Использованы Gradle Wrapper 8.14.3, JDK Temurin 23.0.2, Kotlin 2.2.21 и Compose 1.9.3.
Для первого запуска нужен доступ к репозиториям зависимостей; неполный локальный кеш
не позволяет выполнить первый прогон с `--offline`.

| Kotlin: интерфейс Compose | 42 | 0 | 0 | 0 |
| Всего | 610 | 0 | 0 | 0 |

Итог: `BUILD SUCCESSFUL`. Проверено 56 тестовых классов.

JUnit XML — в `composeApp/build/test-results/jvmTest/`.

## Требование к последующей миграции

Миграция Пуджа меняет организацию кода, сохраняя наблюдаемое поведение:
результаты и причины отказов, выбор целей, перемещения, взятия и реакции,
стоимость способностей, заряд ульты, сроки кулдаунов, итоговое состояние,
историю и совместимость сохранений.

Использовать этот успешный прогон как исходный результат. Новые проверки
добавлять для интеграции нового пути и непокрытых контрактов. Изменения игровых
правил и исправления игровых ошибок рассматривать отдельно от рефакторинга.
