# Общие расширения для новых тел и превращений

Согласованный отдельный блок для Phoenix / Supernova. Правила героев остаются в локальных пакетах.

1. **Типы фигуры:** `Egg` и `Archbishop`, фабрика доски, ходы, атаки, препятствия, отображение и чтение XML. Нестандартные тела запрещены в Classic.
2. **Возможности тела:** `Figure.canBeDisplaced()`, `canUseAbilities()`, `isClassicBody()`. Яйцо запрещает перемещение и активные действия. Ядро проверяет запрет до разрешения ловушек; гибель не считается перемещением.
3. **История личности:** `PieceHeroChange`, `MechanicDefinition.heroChanges`, `PieceHeroHistory`. История тела берёт первоначальное описание через происхождение. Старые эффекты продолжают принадлежать тому же ID.
4. **Исходный состав:** `initialHero` хранит исходный пик, а `HeroRegistry.validateOrigin(..., initialHero)` проверяет исходные данные политикой первоначального героя. Полное превращение не создаёт дополнительный пик.
5. **Перемещения:** совместное применение подготовленных обновлений, запрет столкновений ID, стандартная безопасность короля, снятие права рокировки при перемещении короля или ладьи.
6. **Сохранения:** XML 20 для новых тел; локальные кодеки правил и случайности; восстановление инкубации из событий. Старые XML и каталоги не переписываются.

Для героя по-прежнему нужны `AbstractHero`, неизменяемые Rules, собственные Ability / Definition / StatePolicy и локальное представление. Реализация не добавляет имени героя в `Game`, `ActionEngine`, `ChessBoard` или `DraftScreen`.
