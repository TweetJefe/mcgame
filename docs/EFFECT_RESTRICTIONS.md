# Ограничения воздействий и препятствия

Согласованный отдельный общий блок для Leshy и следующих героев.

## API

`MechanicDefinition.restrictions(context, piece)` возвращает неизменяемый `PieceRestrictions`. Независимые запреты: обычное движение, атаки, способности, предметы, взятие/удаление, принудительный сдвиг, пассивные реакции и активное превращение.

`MechanicDefinition.passageObstacles(context)` возвращает клетки, блокирующие промежуточный участок обычного хода и луча атаки. Коневой прыжок, в том числе у составной фигуры, проходит над ними. Назначение на клетку разрешено; последствия входа задаёт модуль эффекта.

Реестр объединяет ограничения модулей. Состояние и сроки по-прежнему принадлежат `MechanicKey` и локальной механике. Новые API не меняют значения существующих статусов.

## Контекст и проверки

`HeroActionContext` дополнен общим неизменяемым реестром механик партии. `blocks(piece, restriction)` и `passageObstacles()` вычисляют ограничения по реальному состоянию. Производственные пути передают `heroes.mechanics()`. Прежние конструкторы сохраняются для изолированных предпросмотров, с пустым реестром; они не заменяют проверку через Game.

Проверки подключены к обычным ходам, рокировке, способностям, предметам, цепочкам гибели, массовым воздействиям, завершению хода, шаху и восстановлению снимка. Все обновления подготавливаются частно; отказ не расходует бюджет, ресурсы или случайность. Защищённые цели не участвуют в применимых массовых взятиях и перемещениях.

В UI `HeroPresentation.BoardDecoration(BoardEffectContext)` отображает наложенные воздействия на любые клетки, включая пустые. Реестр вызывает представления, подключённые в конфигурации партии. Виджет читает снимок и не вычисляет игровую законность.

Пример: [LESHY.md](LESHY.md). В Game / ActionEngine / ChessBoard нет веток по Leshy или его enum способностей.
