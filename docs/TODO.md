# ToDo: найденные проблемы Moba Chess

Актуально на 7 октября 2026 года. Список составлен по просмотренным исходникам проекта и [документации движка](ENGINE.md). Он включает найденные ошибки, отсутствующие правила, ограничения API и технический долг. Это список задач для следующих изменений, а не утверждение, что весь перечисленный функционал уже должен был быть реализован.

Обозначения: `[ ]` — открытая задача; `[x]` — исправлено и проверено. Приоритеты: **P1** — полноценная шахматная партия; **P2** — надёжность модели и согласованность интерфейса; **P3** — сопровождение и дополнительные возможности. Пункты **D** требуют решения о поведении продукта.

## Текущий Moba-прототип
