# Zeus — ладья

Одиннадцатый герой для пика. В обычной партии Zeus уникален для обеих сторон: выбранного персонажа соперник взять не может. Заменяет ладью на a1/h1 либо a8/h8. На доске обозначается **Z**.

В режиме «Тест скиллов • без КД/заряда» один Zeus стоит на **e2** вместо белой пешки. Второй тестовый Zeus не создаётся. В этом режиме способности бесплатны, но для разряда по-прежнему нужна заряженная цель.

## Скилл — Цепная молния

Первая цель — выбранная вражеская фигура, включая пешку, в радиусе **3 по каждой оси**: вся область 7×7 вокруг героя. Препятствия не мешают. **КД — 1 собственный ход**: способность снова готова в начале следующего собственного хода.

После попадания молния ищет от последней поражённой фигуры ближайшего ещё не поражённого врага в пределах **2 клеток по каждой оси**. Можно перескочить одну клетку, в том числе по диагонали. Близость считается по максимальному расстоянию по осям. При равном расстоянии цель выбирается случайно. Всего поражаются **не более трёх разных врагов**; без подходящей следующей цели цепь останавливается.

Каждое попадание добавляет цели один заряд. **Третий заряд одного источника убивает фигуру. После реального убийства цепь немедленно заканчивается**, а все оставшиеся заряды применившего молнию героя сбрасываются.

## Срок зарядов

Заряды действуют до конца **второго следующего собственного хода источника**, не считая ход применения. Новое попадание обновляет срок всех зарядов этого источника на данной цели.

Например: Zeus применил молнию на своём ходу №1. Заряд остаётся во время собственных ходов №2 и №3 и исчезает в конце №3, если не был обновлён. Заряд привязан к ID цели и следует за её перемещением; обычное взятие цели удаляет её заряды.

## Ульта — Разряд

Цена — **2 собственных взятия**, включая пешек. Отдельного КД нет. Выбор клетки не требуется: случайная доступная вражеская фигура с хотя бы одним зарядом **этого героя** погибает. После убийства все его заряды сбрасываются. Без подходящих заряженных врагов команда недоступна и заряд ульты сохраняется.

Убийства молнией дают обычное золото и собственное взятие. Поэтому после разряда по настоящей фигуре Zeus получает один заряд следующей ульты, как и при любом своём взятии.

## Ginseng: отдельный источник

Ginseng копирует последнее успешное применение Zeus по обычным правилам. Полученная способность действует от самого Ginseng, со следующего собственного хода, один раз, без дополнительной цены или КД.

**Заряды Zeus и Ginseng полностью раздельны**, даже на одной цели. `Z1 G2` — один заряд Zeus и два Ginseng; цель ещё жива. Для убийства один из источников должен самостоятельно накопить три. Разряд Ginseng выбирает только цели с его зарядами. Убийство Zeus не сбрасывает заряды Ginseng на оставшихся живых фигурах, и наоборот. У погибшей цели удаляются все её заряды, поскольку самой фигуры больше нет.

## Взаимодействия

| Ситуация | Поведение |
| --- | --- |
| Король | Не может быть целью, звеном цепи или жертвой разряда |
| Коробка Clownganger | Защищённая цель недоступна первому попаданию, цепи и ульте; существующие заряды продолжают отсчёт |
| Невидимость Faun | Скрытую цель нельзя выбрать первой; автоматическая цепь и разряд могут её поразить |
| Туча или стан | Запрещают активировать способность источнику по общим правилам |
| Иллюзия | Может получать заряды; разряд или третий заряд не убивает пустышку и не даёт наград, снимает заряды данного источника с неё и запускает обычное однократное продление её жизни |
| Гибель Ares | Готовая месть достаёт источник молнии на его фактической клетке |
| Пудж с союзником | Пассажир выходит на клетке погибшего Пуджа и отвечает взятием удалённого источника молнии |
| Гибель Избы | Запускает призыв Бабы-яги рядом по общим правилам |
| Собственный король | Действие целиком отклоняется, если последствия оставляют его под шахом или не позволяют допустимо закончить ход |

Настоящее убийство останавливает цепь. Неудавшееся уничтожение пустышки настоящим убийством не считается. Ульта на иллюзию расходуется, остальных врагов повторно не выбирает.

Способность необязательна и занимает общий лимит одного скилла/ульты за ход. Обычный ход фигуры остаётся обязательным; можно переместить самого Zeus. Подсветка и отклонённые действия не расходуют ресурсы, случайность или бюджет.

## Устройство

Пакет `game.heroes.zeus`:

| Класс | Назначение |
| --- | --- |
| `ZeusRules` | КД молнии, срок зарядов, цена ульты |
| `ZeusAbilities` | Поиск ближайших целей, выбор при равенстве, подготовка убийства и реакций |
| `LightningState` | Неизменяемые заряды по паре ID «источник → цель», срок и журнал попаданий/сбросов |
| `LightningValidator` | Сверка снимка с историей, источников, сроков, цепей и убийств |

`ActionEngine` готовит действие и проверяет королей на временных данных. `Game` публикует только успешный результат, награды и события. `GameSnapshot.lightning()` переносит состояние через интерфейс и восстановление партии. Случайность использует сохраняемый PRNG из `SummonState`; подсветка работает с его копией.

```java
game.useAbility(player, zeusSquare, targetSquare, Ability.CHAIN_LIGHTNING);
game.useAbility(player, zeusSquare, null, Ability.THUNDERSTORM);
```

Обе команды возвращают `MoveResult`; вызывающий код проверяет `isSuccess()`.

## Сохранение и проверки

**XML 12** добавляет `zeusRules` (`lightningCooldown`, `chargeTurns`, `ultimateCaptures`), героя `ZEUS_ROOK` и события `CHAIN_LIGHTNING`, `THUNDERSTORM`, `LIGHTNING_HIT`, `LIGHTNING_RESET`, `LIGHTNING_DISCHARGE`, `LIGHTNING_CAPTURE`. Состояние зарядов восстанавливается из журнала. Каталог **8** содержит одиннадцать выбираемых героев; после двух банов остаётся девять. Старые форматы 1–11 и каталоги 1–7 поддерживаются.

`ZeusTest`, `ZeusSaveTest`, `ZeusUiTest` проверяют геометрию, случайность, третье попадание, остановку цепи, КД, сроки и обновление, независимость источников, обе копии Ginseng, награды, ответные реакции, защиту королей, коробки, тучи, невидимость, иллюзии, повреждённые сохранения, совместимость и реальные клики Compose. Общий набор — **517 тестов**, команда `:composeApp:jvmTest`.
